# NVE-SGFormer：第一步实验设计

## 本轮要回答的问题

在不改变 EEG 主干、分类头和训练划分的条件下，显式的节点级神经血管事件表示（NVE）经过 SGFormer 全局关系建模后，是否能形成比黑盒 fNIRS 空间特征更有效的 CBraMod K/V Prompt。

## 本轮架构

输入为训练集统计量标准化后的 `[B,36,2,100]` HbO/HbR。每个节点生成 23 个不使用标签、不使用 EEG 的显式属性：

- HbO、HbR 各自四个等长时间段的均值，共 8 项；
- HbO、HbR 各自的全局均值、标准差、线性趋势、末段减初段、平均绝对一阶差分、最大值、最小值，共 14 项；
- HbO/HbR 的 Pearson 相关系数，共 1 项。

记节点 `i` 的描述向量为 `e_i∈R^23`：

`z_i = MLP(LN(e_i)) + Geo(p_i) + Emb(i)`

`S = SGFormerGlobal({z_i}_{i=1}^{36}) ∈ R^(36×128)`

`P_spatial = Proj(S) ∈ R^(36×200)`

时间 Prompt 不使用上述统计描述，而继续由参数独立的 HbO/HbR 1D-CNN 编码后拼接得到：

`P_temporal = Proj([CNN_HbO(x_i^O) || CNN_HbR(x_i^R)])`

空间和时间 Prompt 注入冻结 CBraMod 第 8–11 层 CrissCross Attention 的并行 K/V 适配器。外层空间/时间门控保持零初始化。

## 为保证比较公平所做的控制

- CBraMod 全程冻结，EEG 输入保持 `/100`。
- Batch size 4，学习率、损失权重和数据划分沿用前一轮。
- MI 固定训练 50 轮；MA 使用 patience=15 的验证集早停。
- 直接复用 K=4 Top-2 实验已经训练好的 EEG 分类头，不重新随机初始化或训练 EEG 头。
- 本轮不使用 MoPE，避免专家路由与 NVE 表示同时变化。
- SGFormer 仅保留一层全局线性注意力，不使用三角剖分邻接和 GCN。

## 合理但本轮没有应用的方向

1. **显式血流动力学时滞**：在 0–8 秒范围学习 EEG 到 fNIRS 的 HRF/延迟核。本轮只用 fNIRS 生成 Prompt，先避免引入对齐误差和额外超参数。
2. **动态神经血管耦合图**：按 trial 预测 36×36 邻接矩阵、Granger 因果或区域间耦合。本轮没有足够监督来证明边的生理含义，先使用全局注意力。
3. **SGFormer 的局部 GCN 分支**：可加入三角剖分、距离图或功能连接图；本轮去掉 GCN，以检验 NVE 本身和全局关系。
4. **Balloon-Windkessel/HRF 生理损失**：可由 EEG 预测慢血氧响应并与真实 HbO/HbR 对齐；需要先确认当前同步与基线校正足以支持秒级时滞估计。
5. **可学习事件检测器**：用软峰值、可学习分段或多尺度小波替代固定统计量；首轮选择固定描述以保持可解释性并减少过拟合。
6. **一个节点多个事件 Token**：把早期、峰值、恢复期拆成独立 Token；会把空间 Prompt 从36个扩展到108个以上，需在本轮确认方向有效后再做。
7. **NVE 与 fNIRS-T/MoPE 组合**：可将 NVE 作为静态/结构分支、fNIRS-T 作为动态分支，再由专家路由选择；本轮不组合，避免无法归因。
8. **HbO/HbR 反相关与响应方向约束**：并非所有脑区、被试和 trial 都严格满足 HbO 上升、HbR 下降，因此本轮只把相关性作为输入属性，不直接施加强制惩罚。
9. **EEG 条件化 NVE**：让 EEG 事件查询 fNIRS NVE 可能更贴近真正耦合，但也会使 EEG 基线与融合分支不再干净可分，本轮暂不采用。
10. **多 seed 与参数搜索**：首轮仅 seed=1 验证可行性。只有当 MI/MA 至少一个任务显示稳定正增益后，再进行多 seed、注意力残差权重和描述集合消融。

## 预先确定的有效性判断

- 主要指标：Fusion test accuracy 与固定 EEG 基线的差值。
- 同时比较 K=4 Top-2、原 fNIRS-T L1 和已有 SGFormer 版本。
- 检查各受试者的提升是否一致，避免总体提升只由单个受试者贡献。
- 检查空间门控是否离开零，以及 NVE fNIRS 辅助分类是否高于随机水平。
- 若 Fusion 没有提升但 fNIRS 分支改善，说明中间表示有效而注入方式可能仍需调整；若二者都无改善，则优先否定当前固定描述集合。
